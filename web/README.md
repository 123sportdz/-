# واجهة الويب التجريبية (React SPA)

نموذج أولي مستقل بـ **Vite + TypeScript + React 19 + Tailwind CSS 4**. الواجهة عربية RTL، لكنها غير موصولة بمحرّك Python أو `dashboard.py`.

## ما يعمل فعلياً

- قراءة بيانات الفيديو واستخراج إطارات معاينة محلياً في المتصفح.
- إنشاء معاينة قصّ Canvas محلية وتنزيلها.
- إنشاء نصوص محلية؛ ويمكن اختيارياً استدعاء Gemini للنص فقط بعد موافقة مستقلة لكل توليد.
- حفظ التفضيلات والمهام النموذجية في مفاتيح `localStorage` التي تبدأ بـ `elhadath_`.

## ما لا يعمل في هذا النموذج

- لا يوجد تشغيل لـ YOLO أو FFmpeg أو متتبّع الكرة؛ مسارات الحركة والدرجات في شاشة ProShot رسومات توضيحية.
- المهام والإحصاءات ومنشورات القنوات وسجل الحقوق بيانات نموذجية أو إقرارات محلية، وليست سجلات تنفيذ أو تحقق.
- الأتمتة وجلب Telegram ورفع YouTube/Telegram غير متصلة. النشر الفعلي يجب أن يمر عبر `dashboard.py` وبوابات `reelkit.rights` الخادمية.

## Gemini والخصوصية

- لا يُرسل النص إلى Google Gemini دون تفعيل موافقة التوليد نفسه؛ الفيديو والصور لا تُرسل عبر خدمة Gemini هذه.
- مفتاح Gemini يبقى في `sessionStorage` للتبويب فقط، ويُزال من التخزين الدائم عند قراءة الإعدادات. التخزين داخل المتصفح غير مشفّر، وقد تتمكن أي شيفرة تعمل على الأصل نفسه من قراءته؛ لا تستخدم مفتاحاً حساساً ولا تنشر هذا النموذج كموقع متعدد المستخدمين.
- لا تُدخل توكن Telegram أو أكواد دخول. زر إعادة الضبط يحذف مفاتيح هذا التطبيق فقط ولا يمسح بيانات مواقع أخرى.

## التشغيل والاختبارات

```bash
cd web
bun install --frozen-lockfile
bun test
bun run build
bun run dev
```

يتطلب Bun 1.4.4 كما هو مضبوط في CI. اختبارات الويب وبناؤه منفصلان عن اختبارات Python في جذر المشروع.

## البنية

- `src/components/tabs/` — التبويبات.
- `src/components/scout/` — معاينة القص وإطارات الفيديو محلياً.
- `src/components/voice/` — معاينة صوت المتصفح.
- `src/components/modals/` — النوافذ المحلية، بما فيها إقرار الحقوق التوضيحي.
- `src/services/` — التخزين المحلي، مولّد النص، الصوت، ومعالجة معاينة الفيديو.
