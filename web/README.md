# واجهة الويب التجريبية (React SPA)

نموذج أولي مستقل لواجهة مصنع الريلز، مبني بـ **Vite + TypeScript + React 19 + Tailwind CSS 4**. العربية RTL بالكامل.

## الحالة: نموذج واجهة، غير مربوط بالخادم بعد

هذا التطبيق يعمل في المتصفح ويخزّن البيانات في `localStorage` (`elhadath_*`). مهم:

- **لا يتصل بمحرّك المعالجة** في `reel.py`/`dashboard.py` — لا يرندر فيديو فعلياً بعد.
- **Gemini** يستخدم مباشرة من المتصفح للميزات الإبداعية (استوديو المحتوى، الكشّاف) بمفتاح يضعه المشغّل في الإعدادات أو `VITE_GEMINI_API_KEY` — لا يوجد مفتاح ثابت في الكود.
- بوابة الحقوق (`RightsGateModal`) نموذج واجهة فقط؛ **السياسة الملزمة** تبقى بوابة `reelkit.rights` في الخادم. لا تعتمد على هذه الواجهة لاتخاذ قرار نشر.
- عند أي دمج مستقبلي مع `dashboard.py`، يجب أن تمر كل عمليات النشر عبر بوابة الحقوق الخادمية نفسها.

## التشغيل

```bash
cd web
bun install        # أو npm install
bun run dev        # تطوير على http://localhost:3000
bun run build      # فحص أنواع tsc + بناء الإنتاج في dist/
bun run preview    # معاينة نسخة الإنتاج
```

## البنية

- `src/components/tabs/` — التبويبات: مصفوف الريلز، المهام، الهوية والشعار، القناة، الأتمتة، الإعدادات، استوديو المحتوى.
- `src/components/scout/` — مراجعة اللقطات قبل الرندر وتتبع اللقطات.
- `src/components/voice/` — استوديو المعلّق.
- `src/components/modals/RightsGateModal.tsx` — نموذج بوابة الحقوق.
- `src/services/` — التخزين المحلي، Gemini، مولّد الصوت، مؤثرات صوتية، معالجة معاينة الفيديو.

المتطلبات: Node 20+ (أو Bun 1.2+).
