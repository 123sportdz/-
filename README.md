## 1) التثبيت

**المتطلبات:** Python **3.11 – 3.13** (⚠️ 3.14 غير مدعوم من torch)، ffmpeg (يفضّل نسخة فيها `libdav1d`)، ~3-4 GB RAM.
كرت رسومات (GPU) **اختياري** — يشتغل على CPU، بس GPU يسرّع الكشف 10-20 مرة.

### ✅ الطريقة الأتوماتيكية (موصى بها)
> ⚠️ في **PowerShell** اكتب `.\` قبل الاسم: `.\install.bat` و `.\start.bat` (أو `cmd /c install.bat`).
```bat
.\install.bat      :: ويندوز: يختار Python المتوافق + ينصّب CUDA تلقائياً لو عندك RTX + يفحص
.\start.bat        :: يشغّل اللوحة (وينصّب/يصلّح تلقائياً لو ناقص)
```
```bash
./install.sh       # لينكس/ماك
./start.sh
```
> 🩺 إذا واجهت أي مشكلة: `python doctor.py --fix` (يصلّح تلقائياً) ثم `python doctor.py --report`.
> ⚠️ شغّل المشروع **دائماً داخل `.venv`** (start.* يفعل ذلك تلقائياً) — تشغيل `doctor.py`
> بمفسّر نظامي قد يُبلغ "مكتبات مفقودة" كذباً.

### 🔧 الطريقة اليدوية

```bash
sudo apt-get update && sudo apt-get install -y ffmpeg

# 2) pytorch — CUDA إن عندك NVIDIA (أسرع 10-20×) وإلا CPU

# pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu  # CPU

```

### 🚀 عندك كرت NVIDIA (مثل RTX 3060)؟ ثبّت نسخة CUDA بدل CPU

```bash

pip uninstall -y torch torchvision
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
# المفروض يطبع: True NVIDIA GeForce RTX 3060
```

بعدها **كل شي تلقائي** (v1.42+): الكشف يشتغل على الكرت بـ**FP16 + دفعات (batch 8)**
→ تسريع **10-20×** عن المعالج (فحص 15Hz لمقطع دقيقة: من ~4 دقائق إلى ~20 ثانية).
تتحكم يدوياً بـ `--device 0` و `--batch 8` (أو من ⚙️ الإعدادات في اللوحة).

## 2) الاستخدام الأساسي

```bash
# مقطع هدف كامل
python reel.py -i goal.mp4 -o reel.mp4 --name "الحدث" --url elhadath-dz.com

# مقطع من داخل تسجيل مباراة طويل (قص أول ما يشتغل الكشف)
python reel.py -i full_match.mp4 -o goal.mp4 --start 41:12 --end 41:55 --name "الحدث"

# نسخة سريعة (للاختبار أو جهاز ضعيف) — لا تنزل عن --rate 10 وإلا يضعف كشف الكرة الصغيرة
python reel.py -i goal.mp4 -o reel_fast.mp4 --rate 10 --imgsz 960

# بدون هوية / بدون إزالة واترمارك
python reel.py -i goal.mp4 -o reel.mp4 --no-brand
python reel.py -i goal.mp4 -o reel.mp4 --keep-watermarks
```

### 🎯 محرّك التتبّع الاحترافي (v1.23)
| المرحلة | التقنية | الفائدة |
|---|---|---|
| الارتباط | **أقرب-جار داخل بوّابة Mahalanobis** (أمامي + خلفي ثم دمج) | تغطية 100% ودقة ~1.5px حتى مع 7 كشوفات ضجيج لكل لحظة |
| المسار | Kalman **2D** (x,y) سرعة-ثابتة + عتبة ثقة **تكيّفية** | لا يغرق في ضجيج الكاشف |
| التنعيم | **RTS smoother** (تمرير أمامي ثم خلفي) | مسار ناعم **بلا تأخير** (لا يهزّ الكاميرا) |
| الفجوات | **جسر قالب بصري** (مطابقة NCC + تحديث تكيّفي) | يملأ فجوات الكشف بالمظهر |
| الكاميرا | **استباقية (lead 0.13s)** + مرشّح **One Euro** | تسبق الكرة مثل مصوّر محترف |
| الدراما | **تقريب ديناميكي** حتى 1.20× مع سرعة الكرة | إحساس البثّ |
| الجودة | تقرير QA: تغطية، أطول فجوة، شواذ مرفوضة، اهتزاز | ثقة بالأرقام |

**قياس فعلي** على مقطع بثّ 1080p60:
```
المحرّك الكلاسيكي : الكرة مُتبَّعة 75% من الفريمات
المحرّك الاحترافي : تغطية 97% + جسر 21 فريماً + رفض 10 شواذ + أطول فجوة 0.03s
```
**اختبار ضجيج واقعي** (7 كشوفات/لحظة، 85% منها ثقتها <0.2 — مثل مقاطع المصدر):
```
قبل التحسين : تغطية 76-85% | خطأ المسار 18-26 بكسل
بعد التحسين : تغطية 100%   | خطأ المسار 1.4-1.8 بكسل
```
> الجسر يعمل على **شبكة زمنية منتظمة** (لا على صفوف الكشف) — وإلا كان يعبّي صفوف الضجيج
> بدل الفجوات الحقيقية (شوهد 408 فريمات مُجسّرة من 619 كشفاً!).
> العلامة والأثر صارا يُرسمان من المسار الناعم مباشرة → **خط متواصل** بدل ظهور متقطّع.

### 🏷️ لوحة النتيجة تُثبّت فوق الريل (v1.26)
الكاميرا تتحرّك أفقياً ⇒ لوحة النتيجة (فوق) **تخرج من الكادر**. المحرّك يلقى اللوحة تلقائياً:
> منطقة الرسوم **الثابتة** في الشريط العلوي (حواف قوية + حركة زمنية ضعيفة) → تصقيل رأسياً
> بطريقة الصفوف (الحواف) ثم بالحركة (العشب يتحرك، اللوحة لا) → قصّ وإعادة تركيب مكبّرة أعلى الريل.

كل الشروط صارمة (عرض 0.06–0.60، ارتفاع 0.025–0.16، نسبة 1.6–14) — لو أي شرط فشل **لا يُرسم شيء**.
```bash
python reel.py -i مباراة.mp4 --score auto     # أو --score "0,0.04,0.37,0.10" أو --score off
```
> مُتحقَّق على بثّ حقيقي: اللوحة المكتشفة كانت `LES 0 - 1 MAR` + كأس أفريقيا + الدقيقة `81:52`.

ترجيح كتلة الصبغة الأكبر، ثم رفع الإشباع) ويُلوَّن به:
شريط الهوية · وسم الكرة والأثر · حدّ انفجار الهدف · فاصل الشاشة المقسومة.
```bash
python reel.py -i clip.mp4 --accent auto      # أو --accent "#E12D37"
```
> على مقطع أحمر القمصان: `🎨 لون الهوية: RGB(198, 54, 61)` — وتحقّقنا أن الوسم واللوحة أخذوا اللون فعلاً.

### 🩺 شفاء ذاتي + 🎬 مقدمة + 🖼️ مصغّرة ذكية (v1.25)
- **شفاء ذاتي**: لو كان الكشف ضعيفاً (0.2–3 كشف/ثانية) يعيد الكشف تلقائياً بتقطيع ودقة أعلى،
  ويأخذ النتيجة الأفضل فقط لو تحسّنت > 30%. (`--no-retry` للإيقاف)
- **مقدمة سينمائية**: `--hook` — تقريب 1.26× ينفتح إلى 1.00× في أول 0.85s (يخطف الانتباه فوراً).
- **مصغّرة ذكية**: تختار **أوضح فريم** (Laplacian) قرب لحظة الهدف بدل فريم ثابت.
- **منطقة آمنة**: شريط الهوية على 0.76H → **ما يغطّيه زر/عنوان يوتيوب شورتس** (المقاس: 0.777–0.835H).

### 🎬 إعادة بطيئة + انفجار «هدف!» (v1.24)
يلقى المحرّك **اللحظة المفتاحية** (قمة سرعة الكرة = التسديدة، مع تقاطع مع صوت الهتاف)، ثم:
```bash
python reel.py -i clip.mp4 --replay 0.5 --burst --max-dur 58 --thumb -o reel.mp4
```
- **إعادة بطيئة**: نافذة 3 ثوانٍ تُعاد بـ0.5× مع **تقريب (punch-in)** + شارة **«إعادة»** عربية،
  والصوت يُبطّأ معها (atempo) — مثل النقل التلفزيوني.
- **انفجار «هدف!»**: نص عربي كبير ينتفخ ويتلاشى (~1.8s) بوهج وحدّ ملوّن.
- لو ما لقى لحظة واضحة → **يتجاهل بهدوء** ويكمّل (ما يكسر المخرج أبداً).

### الخطوط العربية (v1.22)
الهوية تُرسم بمحرّك كتابة مختلطة: **العربي** بخط Noto Sans Arabic، **اللاتيني** بخط DejaVu —
لأن خط Noto العربي **ما فيه أي حرف لاتيني**، فكان `الجزائر الجديدة TV` والرابط يطلعان مربعات ▯.
لو رمز غير موجود في كل الخطوط → تحذير صريح بدل رسم مربعات. للفحص: `python font_check.py`

## 3) كيف يشتغل (Pipeline)

1. **تطبيع المصدر** — لو AV1/HEVC (OpenCV ما يفكّها) يحوّل بـffmpeg لـH.264 وسيط، ويطلع الصوت منفصل.
2. **تحليل المشاهد** — يقطع المشاهد (histogram diff) ويحسب **مركز حركة اللاعبين** مع تعويض حركة الكاميرا (phase correlation).
3. **كشف الكرة** — أوزان YOLO مدرّبة على كرة القدم (`models/ball_detector.pt`) بـ`imgsz=1280`، وتُحجب مناطق الواترمارك حتى ما تُفهم غلط.
4. **تتبّع** — Kalman بسرعة ثابتة، **متعدد البذور**، مع `coasting` (يتوقّع المسار لما الكرة تختفي لحظة) ورفض القفزات غير الفيزيائية. كل مشهد يُتتبّع لحاله.
5. **الكاميرا الافتراضية** — مزج 75% كرة + 25% مركز حركة، ثم متتبّع من الدرجة الثانية (حد سرعة + حد تسارع) مع **deadzone 95px**: ما يتحرك إلا إذا خرجت الكرة عن حزام الوسط → يمنع الاهتزاز.
6. **التأطير حسب اللقطة** — لقطة واسعة → **قص متتبّع 9:16**؛ لقطة قريبة (حجم اللاعب > `--pad-thresh`) → **الإطار الكامل وسط خلفية مموّهة**.
7. **تنظيف الواترماركات** — `cv2.inpaint` (Telea) بنصف الدقة + دمج بحواف متدرّجة (~7ms/فريم).
8. **الغرافيكس والترميز** — أثر الكرة + هويتك (نص عربي بتشكيل صحيح) → H.264 crf20 + الصوت الأصلي.

## 7) الأداء والحدود

| الحالة | الزمن التقريبي (4 أنوية CPU) |
|---|---|
| مقطع هدف 13 ثانية | ~80 ثانية |
| مقطع 55 ثانية | ~4 دقائق |
| تسجيل مباراة كامل → استخدم `--start/--end` | — |

- المخرج 9:16 من مصدر 16:9 يعني قص ~32% من العرض، لذلك **الكاميرا/التأطير هو أهم شي**. لو اللقطة قريبة، الـpad mode يشتغل تلقائياً.
- مصادر **480p أو أقل** → الكرة صغيرة والكشف يضعف؛ النظام يرجع لمركز الأكشن تلقائياً.
- لتغطية كشف أعلى: `--imgsz 1536` (أبطأ)، أو درّب الكاشف على بياناتك.

  على اللوحات الرسومية الصغيرة (مثل CAF) يكون تقريبي.
- **الأفضل:** كابشن رسالة تيليجرام. الأتمتة تحلّله تلقائياً بـ`title.from_caption`:
  `"د82' | هدف ثانٍ لـ المغرب ضد ليسوتو [2-0]"` -> **«هدف المغرب الثاني ضد ليسوتو | الدقيقة 82 | (2-0)»**.

### 🛡️ عندك مطالبة حقوق (مثل UEFA على بثّ كامل)؟

**الصريح:** لما المطالبة تغطي 100% من الفيديو، لا توجد حيلة تقنية تُلغيها. المشروع
**لا** يخفي مطالبات ولا يخدع بصمة المحتوى (Content ID) — هذا يخالف سياسة يوتيوب ويعرّض
قناتك للعقوبات. اللي يساعد فعلاً هو بناء **عمل تحويلي حقيقي** + توثيقه لأي اعتراض صادق:

```bash
# وضع تحويلي كامل: تعليق أصلي + إسناد مصدر + حزمة اعتراض
python reel.py -i clip.mp4 -o reel.mp4 --transformative --channel "قناة الحدث" \
    --name "الحدث" --url elhadath-dz.com --source-credit "المصدر: UEFA — نقد وتحليل" \
    --caption "تحليل هدف…" --max-dur 58 --thumb
# ينتج: reel.mp4 + reel_thumb.jpg + reel_dispute.md (حزمة الاعتراض)
```

| العنصر | الدور | الأقوى قانونياً |
|---|---|---|
| `--commentary` / `--transformative` | تعليق/تحليل **صوتك الأصلي** لا صوت البث | ⭐⭐⭐ |
| `--source-credit` | إسناد المصدر داخل الفيديو | ⭐⭐ |
| `--max-dur` / `--start/--end` | مقتطف قصير منتقى لا البث الكامل | ⭐⭐ |
| `--rights-package` | `<out>_dispute.md`: توثيق جاهز للاعتراض | ⭐⭐ |
| `--name/--url` | هويتك/علامتك | ⭐ |

في اللوحة: كل مهمة مكتملة عندها زر **🛡️ حزمة اعتراض** (يعرض الجاهزية التحوّلية/100).

> ⚠️ حزمة الاعتراض **توثيق تقني** لعناصر عملك الأصلي، وليست رأياً قانونياً ولا ضماناً.
> القرار للمدّعي/يوتيوب. لا تعارض نيابةً عن ملكية لا تملكها، ولا تعد نشر بثّ كامل.
